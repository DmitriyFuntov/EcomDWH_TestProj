#Описание проекта
Функционал файлов в соответсвии с нумерацией
1. Создает таблицы источников
2. Создает таблицы DWH
3. Наполняет данными таблицу источников
4. Создает процедуры загрузки данных из источников
5. Запускает процедуры из файла 4, создает Процедуру запроса витрины данных и выводит результат

#Запуск проекта
- Создать базу данных в MS SQL Server
- Запустить скрипты в порядке нумерации

При повторном запуске файл с создаием процедур(4), можно не выполнять
